E-Commerce Website
Overview

This is a responsive E-Commerce website built using HTML, CSS, and Tailwind CSS. The project features a modern, clean design optimized for user experience and showcases a fully functional front-end with multiple pages and interactive sections.

The website contains at least 5 main pages, with 3 pages nested within one another for detailed product exploration. Tailwind CSS has been used extensively to create a responsive and visually appealing interface without relying on additional JavaScript frameworks.

Features

Fully responsive layout compatible with mobile, tablet, and desktop devices.

Clean, modern, and user-friendly design using Tailwind CSS.

Multiple pages including:

Home Page

Product Listing Page

Product Details Page

Delivery Details / Product Video nested pages

About / Contact / Reviews pages

Accordion-style sections for product details, delivery information, and product video.

Smooth hover and click interactions using Tailwind utilities.

Reusable components and consistent design patterns.

Pages

Home Page

Showcases featured products, banners, and navigation.

Product Listing Page

Displays a grid of products with images, prices, and quick links.

Product Details Page

Nested sections like Product Details, Delivery Details, Product Video.

Accordion-style sections where only one section is expanded at a time.

Delivery Details Page

Nested under Product Details, includes shipping and delivery information.

Product Video Page

Embedded videos or product media content, nested under Product Details.

Additional Pages

About, Contact, Reviews pages with interactive elements.

Tech Stack

Front-End: HTML5, CSS3

CSS Framework: Tailwind CSS (utility-first CSS framework)

Responsive Design: Fully mobile-first and responsive across all devices
